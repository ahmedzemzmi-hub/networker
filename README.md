networker is a utility used for general networking stuff it includes basics like: 
1. pinging
2. nmap scans
3. remote connection
4. ip addresses managing
it works better on linux and needs these listed dependencies:
1. nmap
2. ping
3. openSSH
4. telnet
5. netcat
6. mosh
7. tigervnc
8. sftp
9. iproute2
